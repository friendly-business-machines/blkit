# Review adjudication

Three independent, read-only source reviews of the same uncommitted diff were completed before fixes (Rust-project, Microsoft, Google). Reviewers did not see each other's findings.

- **Accept — Rust-project, padding boundaries (`src/string_ops.rs`).** A combining mark appended to `"a"` merges with it, so the prior result had fewer graphemes than the requested length. Verify the final count when padding was added; return an error rather than a misleading result. The regression test failed before the fix and passed afterward. Source: https://docs.rs/unicode-segmentation/latest/unicode_segmentation/trait.UnicodeSegmentation.html#tymethod.graphemes.
- **Accept — Rust-project and Microsoft, public scalar panic (`src/string_ops.rs`).** `Serialize` permits types that fail JSON conversion, but `expect` panicked. Return `Result`, propagate it in generated `.bl` calls to `string`, update direct Rust caller documentation, and test a map with non-string keys. The library API test failed to compile against the old return type, and the generated integration test failed against the old emitter; both passed after the fix. Sources: https://docs.rs/serde_json/latest/serde_json/value/fn.to_value.html#errors and https://microsoft.github.io/rust-guidelines/guidelines/correctness/#M-PANIC-IS-STOP (guidance, not a language rule).
- **Decline — Google, avoid cloned names for borrowed calls (`src/codegen.rs`).** Name cloning is also necessary in owned generated expression contexts. Avoiding some clones needs context-dependent emission and extra ownership/test cases. No profiling or measured hot-path impact justifies the added generator complexity now. Source consulted: https://google.github.io/comprehensive-rust/idiomatic/welcome.html#dont-fight-the-borrow-checker (contextual advice, not a rule).

Ponytail-review of the revised diff: **Lean already. Ship.** Shared Unicode/regex helpers and conditional error propagation serve specified behavior; no unneeded abstraction or redundant dependency was identified.

Verification after fixes: `cargo fmt --check`, `openspec validate add-string-expressions --strict`, `git diff --check`, and the full serialized `cargo test -- --test-threads=1` suite passed with `BLKIT_TESTCONTAINERS_HOST=host.containers.internal` and `CARGO_TARGET_DIR=/workspaces/blkit/target` (log: `/tmp/blkit-string-final-cargo-test.log`).
