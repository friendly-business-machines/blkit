# Agent instructions

## Commit Messages

When creating commits or generating commit messages, follow the [commit message conventions](.claude/skills/commitmsg/SKILL.md#commit-message-conventions).

## Specifications

Specs in `specs/` are living, module-aligned documents — the authoritative statement of each module's purpose, design decisions, public API, and behaviour. The format is defined in [specs/project/spec-format.spec.md](specs/project/spec-format.spec.md). Read the covering spec before changing a module, and update it in the same change when behaviour or public API changes.
