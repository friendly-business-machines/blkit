# Examples

> Focused, self-contained demonstrations of specific blkit features.

Each example takes a real-world business process, describes it in plain
language, and then shows a complete, working implementation using blkit.

!!! note "Implementations pending"
    The business overview, rules, and worked examples on each page are published
    now. The runnable Go implementations demonstrate defining and executing
    decisions and processes, which depend on the `decisions` and `processes`
    packages. Those packages are still being built, so each page currently marks
    its **Implementation** section as pending; the blkit code will be added once
    the required packages land.

    Each page also links to its authoritative business-level specification.
