# Examples

> Focused, self-contained demonstrations of specific blkit features.

Each example takes a real-world business process, describes it in plain
language, and then shows a complete, working implementation using blkit.

!!! warning "Implementations pending"
    The example implementations demonstrate defining and executing decisions and
    processes, which depend on the `decisions` and `processes` packages. Those
    packages are still being built, so the per-example pages are not published
    yet.

    The business processes themselves are already specified. The table below
    links to each authoritative business-level specification; the blkit
    implementation will be added as a page here once the required packages land.
